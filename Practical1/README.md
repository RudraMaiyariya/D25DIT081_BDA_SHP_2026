# Practical 1: Linux System Administration and File Management

## Challenges Faced

1. Remembering Linux commands for creating, moving, copying, renaming, and deleting files and directories.
2. Creating the correct project directory structure without a graphical user interface (GUI), unlike Windows.
3. Searching for specific files and content using Linux commands.
4. Moving and renaming files without making path or command errors.

## Solutions

1. Practiced commonly used Linux commands (`mkdir`, `cp`, `mv`, `rm`, `touch`) and referred to the command syntax whenever required.
2. Created directories step by step and verified the folder structure using the `ls -R` command after each operation.
3. Used the `find` command to locate files and the `grep` command to search for specific text inside files efficiently.
4. Verified source and destination paths before executing `mv` commands and checked the results using the `ls` command to avoid mistakes.

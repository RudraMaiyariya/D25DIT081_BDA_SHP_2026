# Practical 12: Customer Sales Dashboard Using Interactive Analytics

## Challenges Faced

1. Loading and processing a large-scale Superstore sales dataset containing sales, profit, order, product, region, category, and customer-segment information.
2. Cleaning and validating the dataset by handling missing values, duplicate records, date fields, numerical values, and preparing the data for dashboard analysis.
3. Creating meaningful KPIs such as Total Sales, Total Profit, Total Orders, Profit Margin, and Average Order Value, along with interactive analysis using Region, Category, Segment, and Time filters.
4. Designing sales visualizations, product-wise profitability analysis, customer segmentation, and quarterly performance analysis to identify important business trends and support management decision-making.

## Solutions

1. Created and loaded a Superstore-style sales dataset into the analysis environment and validated its schema, record count, duplicate records, missing values, sales, profit, and order information.
2. Used data cleaning and transformation operations to prepare date, sales, profit, quantity, region, category, product, and customer-segment fields for analysis.
3. Calculated KPIs including Total Sales, Total Profit, Total Orders, Total Quantity, Profit Margin, and Average Order Value, and generated region-wise, category-wise, product-wise, and segment-wise summaries.
4. Created interactive dashboard visualizations for regional sales, category performance, monthly and quarterly trends, product profitability, and customer segmentation, followed by business insights and recommendations.
